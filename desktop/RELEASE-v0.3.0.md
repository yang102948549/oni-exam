# Oni Scan v0.3.0

Oni Exam을 Oni Scan으로 변경했습니다. 기존 PDF → HWPX 변환에 문서 취합 기능을 추가했습니다.

- 이수증 여러 PDF에서 연수명·이수자 이름 후보를 추출하고 확인·수정 후 `연수명/연수명(이름).pdf`로 복사 저장합니다.
- 영수증에서 날짜·사용처·금액 후보를 추출하고 월별 폴더에 저장합니다.
- 원본 파일을 보존하며 동일 이름의 파일을 덮어쓰지 않습니다.
- kordoc 4.24.54 기반 로컬 OCR과 1단·다단·다른 판형 PDF 변환을 지원합니다.
- 문서 유형과 OCR 모드를 직접 선택할 수 있습니다.

## 사용 시 확인

- 취합 정보는 항목명 기반 인식 후보이므로 원문과 비교해 수정한 뒤 저장하세요. 파일 하나에 여러 이수증이 있으면 먼저 분리해 주세요.
- 일반 PDF는 편집 가능한 A4 1단 문서로 재구성합니다. 원본 단 배치·쪽 나눔의 완전 복제는 지원하지 않습니다.
- 스캔의 복잡한 표·수식·그림은 원본과 확인해 주세요.
- 첫 OCR 실행에는 모델 다운로드가 필요합니다. 문서 인식은 로컬에서 수행합니다.
- Windows x64용이며 코드 서명되지 않은 설치 파일입니다.

기존 Oni Exam의 앱 식별자와 업데이트 저장소를 유지합니다.
